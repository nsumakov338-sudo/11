РОСТЕЛЕКОМ — СИСТЕМА УЧЕТА ЗАЯВОК НА ЛЬГОТНЫЕ ПОДКЛЮЧЕНИЯ И СУБСИДИИ
ПК-версия, C# + WPF + XAML

КАК ЗАПУСТИТЬ
1. Распакуйте архив в обычную папку, например: C:\Projects\BenefitSubsidyDesktop_PCOnly
2. Откройте Visual Studio 2022.
3. Нажмите File / Open / Project or Solution.
4. Откройте файл BenefitSubsidyDesktop.sln или BenefitSubsidyDesktop.csproj.
5. Вверху выберите Debug и Any CPU.
6. Нажмите F5.

ВАЖНО
- Это ПК-приложение сделано на WPF, потому что XAML используется именно в WPF, а не в Windows Forms.
- В проекте нет внешних NuGet-пакетов, чтобы он запускался стабильнее.
- Требуется Visual Studio 2022 с компонентом ".NET Desktop Development".
- Целевая платформа: .NET 8 Windows (net8.0-windows).

ЧТО НОВОГО В ЭТОЙ ВЕРСИИ
- Добавлено реальное подключение к Firebase Realtime Database через REST API.
- Добавлена авторизация Firebase Authentication через Email/Password.
- Добавлена кнопка «Настройки Firebase» прямо в приложении.
- Добавлена синхронизация с Firebase: applications, applicationPrivate, auditLogs, notifications.
- Локальный демо-режим оставлен как запасной вариант.
- Если Firebase не настроен, программа всё равно запускается и работает локально.

КАК ПОДКЛЮЧИТЬ FIREBASE
Подробно смотри файл README_FIREBASE_RU.txt.
Кратко:
1. В Firebase включи Authentication → Email/Password.
2. Создай пользователя operator@test.ru / 123456 или своего оператора.
3. Импортируй Firebase/firebase_database_import.json в Realtime Database.
4. Замени UID-заглушки на настоящие UID из Authentication → Users.
5. Запусти программу.
6. Нажми «Настройки Firebase».
7. Включи Firebase-режим и вставь Database URL, Web API Key, Email и пароль.
8. Нажми «Синхронизировать».

ГДЕ ХРАНЯТСЯ ЛОКАЛЬНЫЕ ДАННЫЕ
После запуска приложение создаёт папку:
%LOCALAPPDATA%\RostelecomBenefitSubsidyDesktop

Внутри:
- applications_local.json — локальная база заявлений;
- sync_queue.json — очередь изменений при оффлайне;
- fake_cloud_database.json — демонстрационная облачная база;
- structured_log.txt — структурированный лог INFO / WARNING / ERROR.

РЕАЛИЗОВАНО
1. Добавление, редактирование, поиск, фильтрация, сортировка и удаление заявлений.
2. Автоматическая генерация ID вида ЛГ-ГГММДД-XXX.
3. Поля: ФИО, телефон, адрес, категория, тип услуги, статус, приоритет, дата, документ, комментарии, менеджер, служебная метка.
4. Валидация через регулярные выражения и кастомные проверки.
5. Внутренний и внешний комментарии с ограничениями длины.
6. Структурированное логирование действий в файл.
7. Экспорт в Excel (.xls) и Word (.doc) через HTML-таблицы со стилями и группировкой.
8. Локальная очередь, оффлайн/онлайн режим, LWW.
9. Реальная Firebase-синхронизация после заполнения настроек.
10. Аналитика по категориям, статусам и типам услуг за день/неделю/месяц.
11. Индикатор подключения к облаку.
12. Служебные метки и внутренние комментарии вынесены в applicationPrivate и скрываются от менеджера в будущей мобильной версии.

КАК ПРОВЕРИТЬ FIREBASE-СВЯЗЬ
1. Включи Firebase-режим через кнопку «Настройки Firebase».
2. Добавь заявку в приложении.
3. Нажми «Синхронизировать».
4. Открой Firebase Console → Realtime Database → Data → applications.
5. Там должна появиться заявка.

КАК ПОТОМ СВЯЗАТЬ С ТЕЛЕФОНОМ
Для телефона нужно отдельное мобильное приложение, например .NET MAUI C# + XAML или Android-приложение.
Оно должно использовать тот же Firebase Database URL и тот же путь applications.
Тогда изменения с ПК будут уходить в Firebase, а мобильное приложение будет читать эти же данные.
