Версия с отдельными формами
===========================

Что изменено:
1. Главное окно теперь содержит только меню, статус облака и сводную статистику.
2. Список заявок вынесен в отдельную форму ApplicationsWindow.
3. Добавление и редактирование заявки вынесено в отдельную форму ApplicationFormWindow.
4. Подробный просмотр заявки и быстрое изменение статуса вынесены в ApplicationDetailsWindow.
5. Аналитический график вынесен в AnalyticsWindow.
6. Экспорт Excel/Word и отчет за период вынесены в ExportWindow.
7. Просмотр локального журнала действий вынесен в LogsWindow.
8. Настройки Firebase остались отдельной формой FirebaseSettingsWindow.

Как запустить:
1. Распакуйте архив.
2. Откройте BenefitSubsidyDesktop.sln в Visual Studio 2022.
3. Убедитесь, что установлен компонент .NET Desktop Development.
4. Нажмите F5.

Firebase:
- Если Firebase не настроен, программа работает в демо-режиме с локальной демонстрационной синхронизацией.
- Для настоящей синхронизации откройте «Настройки Firebase» и укажите Database URL, Web API Key, email и пароль оператора.
