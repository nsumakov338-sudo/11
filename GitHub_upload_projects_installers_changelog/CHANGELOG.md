# Changelog

Все заметные изменения проекта фиксируются в этом файле. Формат основан на Keep a Changelog, версии ведутся по Semantic Versioning.

## [1.0.0] - 2026-06-09

### Добавлено
- Десктопное WPF-приложение для оператора: заявки, поиск, фильтры, экспорт, логи и настройки Firebase.
- Мобильное MAUI Android-приложение для менеджера: вход, список назначенных заявок, карточка заявки и изменение статуса.
- Синхронизация данных через Firebase Realtime Database.
- Локальный кэш и очередь изменений для работы при отсутствии сети.
- Установщики: архив для Windows и APK-файл для Android.

### Изменено
- Общие данные заявки и служебные операторские поля разделены по разным разделам Firebase.
- Уточнены проверки ФИО, телефона, даты подачи, статуса и длины комментария.

### Исправлено
- Исправлена обработка некорректных данных при сохранении заявки.
- Исправлена логика сохранения изменений менеджера при нестабильном подключении.
- Исправлены сообщения пользователю при ошибке авторизации и синхронизации.
